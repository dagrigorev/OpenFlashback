# OpenFlashback

OpenFlashback is an open-source engine, written from scratch in Rust, for **Flashback (1992)**
on modern PCs, using the data files from **your own copy** of the DOS game. It is a sister
project of [OpenBlood](https://github.com/dagrigorev/OpenBlood), built the same way.

![Level 1 drawn by OpenFlashback](https://raw.githubusercontent.com/dagrigorev/OpenFlashback/master/screenshots/level1.png)

> OpenFlashback contains **no** Flashback game content (levels, graphics, sounds, music or
> executables). Without the original files it does nothing. Flashback is © 1992 Delphine
> Software International.

**Status: early.** The original pictures, level rooms, room connections and Conrad's sprites are
read and drawn; Conrad can walk between rooms. There is no game logic yet. See
[Roadmap and Known Issues](Roadmap-and-Known-Issues).

# Controls

| Action | Keys |
| --- | --- |
| Start (title screen) | Enter / Space |
| Walk | Left / Right (A / D) |
| Floor up / down (into the room above / below at the edge) | Up / Down (W / S) |
| Jump to level 1-5 | 1 - 5 |
| Previous / next room of the level | `[` / `]` |
| Fullscreen | F11 |
| Back to title / quit | Esc |

These are development controls until Conrad's real moves are implemented.
